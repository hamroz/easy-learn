# Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Flame logo + input polish, a configurable font catalogue, Codex/OpenCode/OpenRouter providers with per-task
routing, presets and fallback, and an authenticated authoring API for Claude Code.

**Architecture:** Settings gain jsonb `ai`, `fonts`, `secrets` and `author_token_hash`. Providers expose
`complete()`, `health()` and `listModels()`. `aiFor(userId, task)` resolves the active preset's route, and
`completeWithFallback`/`generateJsonRouted` retry once on the fallback model.

**Spec:** `docs/superpowers/specs/2026-10-05-round2-models-fonts-authoring-design.md`

## Global Constraints

- Default enabled fonts: literata, inter, plex. Enabled list never empty.
- OpenRouter key encrypted with AES-256-GCM using a key derived from `APP_SECRET` (scrypt); never sent to the browser.
- Task keys: course, cover, plan, writing, simulation, answer, rewrite, quiz.
- Fallback tried once, only after ProviderError (not `aborted`) or AIOutputError.
- Bearer-authenticated author requests skip the Origin check; cookie requests keep it.
- Claude provider hidden from Settings, code kept.

## Review Focus

1. Corrupt or missing `APP_SECRET` → saving a key fails with a clear message; reading never crashes settings.
2. A model removed from the library but still used by a preset → the route still runs (library only filters pickers).
3. OpenCode/Codex not installed or signed out → model library shows the reason, generation errors carry the sign-in command.
4. Author API with a malformed course → 400 with the validation issues, nothing written.
5. Legacy settings rows (provider/lessonModel/chatModel) → migrated into a working preset.
